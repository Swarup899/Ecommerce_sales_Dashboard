# Ecommerce_sales_Dashboard
## 📊 Overview
This project analyzes eCommerce sales performance using Power BI.  
It provides insights into revenue trends, top products, customer behavior, and regional performance. It Used complex parameters to drill down in worksheet and customization using filters and slicers
Created connections, join new tables, calculations to manipulate data and enable user driven parameters for visualizations
Used different types of customized visualization (bar chart, pie chart, donut chart, clustered bar chart, scatter chart, line chart, area chart, map, slicers, etc)

## 🧰 Tools Used
- Power BI
- Excel / CSV
- DAX & Power Query
